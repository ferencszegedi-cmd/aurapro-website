# FELÚT logó és szlogen

## Szlogen

**„Van kiút. Van felút."**

- A programnév (**FELÚT**) a *felzárkózás* és az *út* szavakból képzett márkanév:
  a lefelé vivő utakkal (drog, uzsora, iskolaelhagyás) szemben a felfelé vezető
  utat állítja szembe.
- Alternatív szlogenek kampányhasználatra:
  - „Honnan indulsz, nem dönti el, hová érkezel."
  - „Emeld fel a fejed!"

## A logó szimbolikája

| Elem | Jelentés |
|---|---|
| Felkelő nap küllőkkel | a roma zászló vörös kereke (chakra) mint felkelő nap: új kezdet |
| Kék ég / zöld dombok | a roma zászló színei (kék ég, zöld mező) |
| Emelkedő út a nap felé | a „felút": a felzárkózás útja |
| Hangjegyek | a zene mint közös nyelv — L.L. Junior nagyköveti szerepe |
